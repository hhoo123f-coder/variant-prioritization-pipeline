## Framework (Richards et al., 2015)

| Tier | Meaning |
|------|---------|
| Pathogenic | Causes disease |
| Likely pathogenic | >90% probability |
| VUS | Uncertain significance |
| Likely benign | >90% probability benign |
| Benign | Does not cause disease |
