# Module 1 — Prioritization Tools Notes

## What is Variant Prioritization?

Ranking genetic variants by their likelihood of being
relevant to a phenotype or disease.

## Tools (from study material)

### Annotation Tools
| Tool | Purpose |
|------|---------|
| VEP | Consequence, impact, SIFT, PolyPhen |
| ClinVar | Clinical significance |
| gnomAD | Population frequency |

### Prediction Tools
| Tool | Type | Output |
|------|------|--------|
| SIFT | Substitution | 0-1 |
| PolyPhen | Substitution | Probably/possibly/benign |
| CADD | General | 1-99 |
| REVEL | Missense | 0-1 |
| AlphaMissense | Missense | 0-1 |
| SpliceAI | Splice | 0-1 |

### Prioritization Tools
| Tool | Input |
|------|-------|
| Exomiser | Phenotype + variant |
| LIRICAL | HPO + variant |
