# Module 1 — Variant Types in Our Dataset

## Background (from types of genetic variation.pdf)

| Type | Description |
|------|-------------|
| SNV | Single nucleotide variant |
| Missense | Changes an amino acid |
| Nonsense | Creates early stop codon |
| Deletion | Removes DNA |
| Insertion | Adds DNA |
| Repeat expansion | Repeats codons |
